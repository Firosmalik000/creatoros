# UI and UX

The durable visual decisions are in `DESIGN.md`.

## Experience rules

- Public surfaces are content-first, editorial, server-rendered, and mobile-first.
- Operational surfaces optimize scanability and task completion.
- Forms have labels, descriptions where useful, validation feedback, disabled/loading states, and recovery copy.
- Lists render loading, error, empty, and success states as applicable.
- Buttons are semantic buttons; links navigate; neither is replaced by clickable `div` elements.
- Motion respects `prefers-reduced-motion`.

System copy belongs in locale dictionaries. Names, handles, brand names, and other proper nouns are not translated.
